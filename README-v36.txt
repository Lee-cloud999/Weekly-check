Weekly Check v36 · 복제 진단판

GitHub 저장소 루트의 service-worker.js 파일만 이 파일로 교체하세요.

이 버전은 앱의 기록/Firebase 구조를 변경하지 않습니다.
페이지를 불러올 때 진단 코드만 임시로 삽입합니다.

업로드 후:
1. Weekly Check를 새로고침합니다.
2. 한 번 더 새로고침합니다. (새 Service Worker가 제어권을 잡기 위해 필요할 수 있습니다.)
3. 이번 주 화면 아래의 '복제 진단 보기'를 누릅니다.
4. 진단 화면을 캡처해서 ChatGPT에 보내주세요.

표시 내용:
- 현재 주와 앞/뒤 주의 로컬 항목 수
- Firebase 항목 수
- 로컬/서버 내부 중복 수
- 로컬과 Firebase가 같은지
- 인접 주가 현재 주와 통째로 같은지
- 렌더링/저장/Firebase 수신 횟수

진단 기능은 기록을 수정하거나 삭제하지 않습니다.
